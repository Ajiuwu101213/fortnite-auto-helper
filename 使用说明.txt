================================================================
 ★ 第一次用（必看，30 秒）：先填你自己的游戏名字
================================================================
双击「启动.bat」后，请在黑窗口里：

    按 4  回车  →  输入你在堡垒之夜里的游戏名字  →  再回车

为什么必须先做这一步？
  程序判断「你现在是不是在局内、还活着」靠的就是**屏幕左下角队伍列表里你的名字**。
  名字填错 / 没填，它就永远认不到你 → 防挂机动作不会启动 → 你在局内站着不动，
  后果有两个：
    · 更容易被游戏当成挂机踢出去；
    · 也可能触发堡垒之夜自己的休眠机制——游戏会弹出「已进入休眠模式」，画面被盖住，
      要人回来手动点「继续游戏」才能接着打。程序本来有自动点「继续游戏」的兜底，
      但那是靠识别休眠框上的字；名字认不到时它连「在局内」都不敢认，等于这道兜底
      也指望不上——所以名字一定要填对。

  名字要跟游戏里显示的**完全一致**（含空格、特殊符号、大小写；建议直接复制）。
  不确定的话：进一局游戏，看屏幕左下角队伍列表最上面那一行，那就是你的名字。

填错了 / 名字里带 OCR 不好认的符号怎么办？
  先按 4 重新填。如果还认不到（日志里出现 WARN ... 看不到名字），可以按 5 切到
  「宽松模式」——认不到名字也照做反挂机动作（仍然只在对局内、且只在游戏窗口前台时才动）。
  正常情况请保持「严格模式」（默认），它更安全：没有名字就绝不动手。

名字文件存在哪里？
  就是本文件夹里的 玩家名字.txt（按 4 修改时会自动写入，第一行就是你的ID）。
  把它删掉就会退回作者测试号（会出现红色警告）。

  零、发给朋友 / 换电脑：需要装什么？（不用装 Python）
================================================================
不需要装 Python、不需要装任何运行库、不需要管理员权限。

  这个文件夹里已经自带了一个完整的 Python 运行时（python 子文件夹，约 150MB），
  双击「启动.bat」它会优先用这个自带的 python。所以：

  · 把【整个文件夹】拷过去即可（不要只拷几个文件，python 文件夹必须一起带着）
  · 对方双击 启动.bat 就能用，不用 pip install 任何东西

唯一依赖是系统自带的「Windows OCR（光学字符识别）」要有中文语言包：

  · Windows 10 / 11 自带 OCR，绝大多数中文系统默认就有
  · 怎么确认：打开程序，看界面的「识别」那一行
       识别    严格·中文OCR正常   → 正常，能读中文
       识别    严格·中文OCR缺失   → 缺中文 OCR，程序读不到界面文字（红色）
  · 缺了怎么装（程序里按 6 就行，一次性，之后永久可用）：
       按 6 回车 → 会弹「用户账户控制(UAC)」→ 点「是」→ 等它下载安装（几十 MB）→ 自动重新检测
       装完若还显示缺失，重启一下程序或电脑再试。

     也可以手动装（没有管理员权限、或者按 6 失败时）：
       设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项
       → 找到「光学字符识别 / OCR」→ 安装 → 重启程序

     ⚠ 说明：装这个必须过一次管理员授权（Windows 的限制，任何程序都没法悄悄装），
       所以按 6 之后一定会弹 UAC 窗口，点「是」就行。
    （Windows 10 路径类似：设置 → 时间和语言 → 语言 → 中文(简体) → 选项）
  · 也可以让对方在命令行跑一次自检：
       python\python.exe fortnite_bot.py --check-ocr

其它可能遇到的两件小事：
  · 第一次双击 启动.bat，Windows 可能弹「已保护你的电脑」（SmartScreen）
      → 点「更多信息」→「仍要运行」。这是因为 .bat 没有数字签名，不是病毒。
  · 游戏请用「全屏」或「无边框全屏」，并且主屏 1920×1080 以上；
    脚本按屏幕百分比 + 识别到的文字位置点击，换了分辨率也不会点歪。

  识别    严格·中文OCR正常  我的ID  YOUR_GAME_NAME
  动作    [DRY] 点击开始 (347,1378)

  ┌────────────────────────────────────────────────────────────────┐
  │ 现在用的是作者测试号 “YOUR_GAME_NAME”                          │

然后（注意：数字要按回车才生效，屏幕上能看见自己打的字）：

  1 回车  =  开始自动挂机（脚本自己去点「开始」、匹配、上巴士、跳伞、等死、回大厅、再开一把）
  2 回车  =  停止挂机（脚本停在后台待命，随时可以再开始）
  3 回车  =  退出程序（会再问一次「确定退出吗？再输入 3 回车」，防止误触）

  输入之后，界面上的「上次操作」那一行会显示你刚才做了什么，例如：
      上次操作  收到 1 回车 → 已开始挂机（Alt+Tab 切回游戏即可）

  不会直接消失：退出时窗口会停住，显示「[程序已退出] 想继续挂机，请重新双击 启动.bat」，
  按任意键才关。如果哪次不小心关掉了窗口，重新双击 启动.bat 就行，不会丢东西。

双击 启动.bat 会先播一段约 1.5 秒的开场动画（金色徽章逐行点亮 → 标题一个字一个字打出来
→「正在初始化 OCR 引擎」进度条），按任意键可以跳过；主界面按 [8] 可以重播。
（不想要动画：启动时加参数 --no-anim；想只看动画：--anim）

输入 1 回车后，程序会自动把堡垒之夜切到前台一次；之后它只在游戏是前台时才操作，
不会抢你的鼠标键盘，也不会跑到别的窗口上去乱点（想切出来看界面随时 Alt+Tab）。
（挂机久了游戏会自己弹「已进入休眠模式 / 继续游戏」，脚本会自动点「继续游戏」接着打。）

● 屏幕上出现「跳过」时**一律点掉**——不管是玩家调查问卷、过场动画、新手指引、
  活动介绍还是更新公告，只要这个浮层上有「跳过」两个字（英文版 SKIP 也认），
  就自动点它。这类浮层会盖住下面所有界面，不点掉的话后面的「开始」「返回大厅」永远点不到。

 三、它到底在干什么
================================================================
每 3 秒截一次屏，用 Windows 自带的 OCR 把屏幕上的中文认出来，然后：

  1. 大厅看到「开始」            → 点开始
  2. 匹配中（搜索服务器 / 取消）  → 只看着，不动
  3. 加载中（连接中 / 大逃杀）    → 只看着，不动
  4. 战斗巴士（船长是 + 倒计时）  → 等到剩 20 秒左右按空格跳伞（没跳成就重试，最多 3 次）
  5. 落地                        → 不主动打架；每 15 秒左右来「一串」8~10 秒的动作
                                    （走路/冲刺/蹲走/跳/平滑转视角/切枪/开枪/跳舞/
                                     F 互动后长按左键 10 秒 / 自动朝队友走），
                                    让游戏以为有人在玩，不会弹「休眠模式」
  6. 自己死了但队友还活着        → 什么都不做，继续观战（此时对局没结束，屏幕上没有「返回大厅」）
  7. 队友全死 / 全队吃鸡，弹出结算页面，页面上有「返回大厅」→ 鼠标点它
  8. 回到大厅看到「开始」        → 再点开始，无限循环

  它按的键只有：跳伞时按空格；局内反挂机时随机按一下 W/A/S/D 或 B、点左键、转视角；
  F9 / F10 是启停（这两个是你自己按，不是它按）。
  全程不按 Esc、不按回车，也不做任何"离开对局"的操作——唯一的退出途径就是：
  结算页面出现「返回大厅」，鼠标去点它。对局没结束时它永远不会替你退赛。
  （反挂机的小动作只在「对局进行中」这一种画面上做，大厅/结算页/弹窗/菜单里绝不乱点，
    所以不会误点到「返回大厅」「开始」这类按钮。）
  这是什么动作？每 15 秒左右来「一串」，每串连续操作 8~10 秒，不是点一下就完。
  每串随机五选一：
    A 综合串（20%）：按住 W 走 3~4 秒 + 平滑转视角 100~200 度（不低头）→ 点/长按左键
                    → 换武器（数字键 1~5，偶尔滚轮）→ 有时换方向再走一段并更大角度甩视角
                    → 有时跳一下 → 约 1/3 概率按 B 跳舞（按 B 开轮盘、按 1 选第一个表情，
                    之后固定等 10 秒让动作播完）
    B 冲刺串（7%）：按住 W+Shift 冲刺 5 秒（不松手）→ 空格跳一下 → 继续 W+Shift 3 秒 → 才松开
    C 蹲走串（7%）：按住 W+Ctrl 蹲着走 5 秒（不松手）→ 空格跳一下 → 继续 W+Ctrl 3 秒 → 才松开
    D 互动串（16%）：按一下 F（互动/使用）→ 等 1 秒 → 按住鼠标左键不放 10 秒 → 松开
    E 朝队友串（50%）：自动朝队友走 —— 在画面里找队友的名字，按它偏左/偏右来转视角，对准了就按住 W 走过去。
                     · 名字在屏幕中间：按左右偏差平滑转过去（右偏右转、左偏左转）；
                     · 名字在屏幕下方：说明队友在「背后/身下」——只做左右转身去找（有时直接转 100~160°），
                       绝不低头看地面，也不往前猛冲，只小挪一步；
                     · 名字在屏幕上方：可能是自己正低着头（队友在前方）或队友在空中——
                       也只按左右偏差转，不抬头也不低头。
                     连续两次找不到他（死了/走远）就换下一个队友；都找不到就左右探头 + 沿原方向小步走。
                     ★ 开局会先"记住"左下角队伍栏里每个队友名字所在的那一块，
                       之后画面里这些位置一律不算"队友在屏幕上的方向"，
                       所以不会出现"往左下角队伍栏方向转身"这种尴尬操作。

  其它移动类动作（A 串里的走位）已经调少了，但**跳舞、切枪、点左键的频率保持正常**。

  所以角色在对局里会持续走、冲刺、蹲走、跳、转身、切枪、开枪、跳舞，看起来像真人在玩。
  想关掉这套动作：启动时加参数 --no-fidget。

  转视角是「按角度」转的，不是一瞬间跳过去：
    · 第一段走路时，总共转 100~200 度；第二段换方向时，总共转 150~300 度；
  · 只左右转，**不上下看**（不会低头看地面）；转的速度约 190~200 度/秒，像人甩一下视角；
    · 每一度都拆成很多小步（每秒约 90 次鼠标微动），所以看着是平滑地一点点转。
    · 转多少像素 = 度数 × 「每度多少像素」，这个数存在 设置.txt 的 px_per_deg。
      默认 5.9 px/度（= 0.17 度/px），是在 15% 灵敏度下用屏幕顶部罗盘刻度实测出来的。
      换算：45° ≈ 265px，90° ≈ 531px，180° ≈ 1062px，一整圈 360° ≈ 2124px。

  换了灵敏度 / 换了电脑怎么办？→ 进一局、确保自己活着（顶部有罗盘刻度），
  然后在黑窗口输入 7 回车：它会临时把游戏切到前台、轻转两下视角，从罗盘刻度测出
  两个数并写进 设置.txt：
      px_per_deg      = 屏幕上每转 1 度占多少像素（显示用）
      counts_per_deg  = 每转 1 度要发多少鼠标计数（**真正决定转多少**，默认 12.16）
  界面「视角」那一行会跟着变。观战时没有罗盘，程序会直接告诉你「没测到」。
  （正在观战/已经死了的时候测不了——观战画面没有罗盘，程序会直接告诉你没测到。）

  它怎么判断「现在是不是局内」？必须同时满足三条：
    ① 屏幕上出现对局 HUD 的文字：收集地图碎片 / 打开宝箱 / 风暴圈 / 剩余；
    ② 屏幕上没有任何局外界面的文字：商城、仓库、任务、返回大厅、搜索服务器、船长是、
       继续游戏（休眠框）……只要出现一个，就当「不是局内」，绝不动手；
    ③ 这条 HUD 文字必须出现在左上角任务条区域（x<900, y<300），或者屏幕上同时有
       两个不同的 HUD 词（比如「收集地图碎片」和「打开宝箱」同时出现），或者屏幕
       顶部出现方位条（「东北 / 东南 / 北 / 东 … + 角度数字」，这栏只有活着在局内才有），
       ；
    ④ 连续 2 次扫描（约 5~10 秒）都判成局内，才真的开始动，防止某一帧 OCR 认错。
    ⑤ 最准的一条是「你自己的名字」：屏幕左下角队伍列表里出现你的游戏ID，就说明「在局内
       而且还活着」；名字不在那个位置（死了在观战 / 在结算页 / 在大厅），它就不做任何动作。
       程序不写死坐标，而是按屏幕百分比找：在「屏幕左边 42% 宽 × 下面 32% 高」这块区域里
       找名字，所以你把 UI 比例调大调小都不影响（实测 UI 缩放后名字仍落在左 3%、高 85%）。
       ★ 第一次用请先在主界面按 4 把「我的游戏ID」改成你自己的名字；也可以直接编辑
         文件夹里的 玩家名字.txt（第一行写你的ID，不要空格）。不改的话默认是作者测试号。
    ⑥ 补充：曾经试过"数左下角血条像素的颜色"当判据，它能认对局内，但死亡观战页、结算页
       的整屏紫色背景会大面积误命中（死亡页连续 194 行、结算页 124 行都被当成血条），
       所以这条已经弃用，现在只用文字判据（HUD 词 / 方位条 / 左下角名字）。
  再加一条铁律：只要屏幕上出现任何一个局外界面词（商城、仓库、任务、返回大厅、
  搜索服务器、船长是、继续游戏……），不管 HUD 词有几个，一律当成「不是局内」。
  所以就算某几个字在局内局外都会出现（比如任务进度文字），也不会误动。

也就是说：它只学「怎么开一局、什么时候跳伞、死了怎么退出来、退了怎么再开一把」，
不参与战斗，所以掉分、战绩都别指望它 :-)


================================================================
 四、常见问题
================================================================
Q: 双击没反应 / 提示找不到 Python？
A: 一定要整个文件夹一起拷贝（里面有 python 这个子文件夹，约 150MB），
   别只拷 .bat 或 .py 出去。

Q: 启动了但脚本一动不动？
A: 因为你切到黑窗口上它就不动了（设计如此，防止乱点你的窗口）。
   按 Alt+Tab 回到游戏，2 秒内就会自己继续。

Q: 我中途想自己玩？
A: 按 F9 停止。想再挂机按 F10，或者回黑窗口输入 1。
  说明：输入 1 回车后，程序会自己把堡垒之夜窗口切到最前面一次；之后全程不再抢焦点，
        你可以随时 Alt+Tab 切出来看界面。

Q: 会封号吗？
A: 这是「截屏 + 认字 + 模拟鼠标键盘」，不注入、不读内存、不改游戏文件。
   但仍属于第三方自动化，风险自负，建议只在娱乐局用，别拿去打排位。

Q: 分辨率 / 窗口模式？
A: 自动读当前屏幕分辨率，建议游戏用全屏。副屏、窗口化暂时不支持。

Q: 跳伞时间不对 / 落点很怪？
A: 巴士倒计时认不准时它靠「上车满 18 秒」兜底，偶尔会跳早或跳晚，不影响后面循环。

Q: 屏幕上没字（纯图标弹窗）它认不出怎么办？
A: 它不会乱按。程序里没有任何「键盘兜底」——只认字、只用鼠标点认出来的按钮，
   所以认不出时就停在那儿等下一轮再认（不会误按 Esc 把对局退掉）。
   真卡住了就按 F9 停、手动点一下，再按 F10 继续。

Q: 我先开挂机助手、游戏还没开，行不行？
A: 行。这时候界面会显示：
       状态    ● 运行中
       画面    未开游戏·请打开游戏

【朋友电脑上「点歪」/ 点到「装备一个精灵」怎么办 (v1.6.5)】
症状: 明明是要点「开始」, 结果点到了上面那行「装备一个精灵」, 或者整体偏左上。
原因: 那台电脑的 Windows 显示缩放不是 100%(常见 125%/150%)。
     旧版虽然设了 DPI 感知, 但在 per-monitor 缩放下截图拿到的是"逻辑像素",
     而鼠标点击用的是"物理像素", 坐标被整体缩小 → 落点偏左上。
v1.6.5 修法:
  1) 强制 per-monitor-v2 DPI 感知(失败退回 per-monitor / 系统级);
  2) 截图尺寸与系统像素不一致时, 自动按比例换算坐标, 并在日志里 WARN 一行;
  3) 每次点击前都记录"点的是哪个文字框", 日志能看到例如:
         点击开始 (363,1404) 「开 始」@326,1385-401,1424
  4) 新增点击黑名单: 只要文字里含 装备/精灵/仓库/商城/通行证/任务/生涯/赛事/商店/
     充值/购买/背包/设置/好友/工会/社交 —— 一律不点(带"装备"的绝不点)。
自己排查: 看 bot_log.txt 第 1 行  屏幕: 截图 WxH / 系统 WxH / DPI=xxx
  · 两边一致 + DPI=per-monitor-v2 → 坐标系没问题; 还点歪就把日志发我;
  · 两边不一致                   → 已自动换算, 若仍偏请把这行发我。

【F9 / F10 不灵怎么办（v1.6.10 起）】
  先确认：机器人进程要在跑（启动器按 1 之后才算在跑），F9/F10 是发给这个进程的全局热键。
  1) 自检键盘通道：在包目录打开命令行，运行
       python\python.exe fortnite_bot.py --hotkeys 10
     然后按 F9 / F10，屏幕上会打印「识别到 F10(开始)」；一个都没有 = 键盘事件被别的程序拦了
     （常见：以管理员身份运行的游戏加速器/宏软件/直播工具）。
  2) 备用通道：程序还认 控制.txt。启动器按 1 / 按 2 时会自动写这个文件，
     机器人每轮都会看它 —— 所以就算 F9/F10 完全失灵，按 2 也能停、按 1 也能再开始。
     你也可以手动在包里放一个 控制.txt，内容写 start 或 stop，机器人读到就执行并清空。
  3) 现在 F9/F10 同时用两种信号判断（低比特「按过一次」+ 高比特「正按住」的上升沿），
     按住不放也能识别，轮询不会再漏。

【关于「奔跑前会按一次 F」（v1.6.15）】

      D 串 = 按稿子键(F) 切稿子 -> 等 1 秒 -> 长按左键 10 秒挖矿 -> 再按一次稿子键切回武器
  v1.6.15 起：
    · D 串收尾会再按一次稿子键，把武器切回来（不再拎着稿子结束）
    · E 串（朝队友冲刺）起跑前有 75% 概率先按 1 切回 1 号武器槽，确保是持枪跑
    · E 串本身从头到尾都不会按 F
  如果你先看到 F 再看到奔跑，是两串挨着播（D 播完接着 E）；现在不会再出现「拎着稿子跑」。


【D 串跟着「稿子」绑定走（v1.6.16）】
  你说的没错：那个「按一下 F 再长按左键 10 秒」的 D 串，用的就是「稿子」这个绑定。
  改稿子 = 改 D 串按的键，不用改代码：
      稿子 = 1  -> D 串按 0x31（数字键 1）
      稿子 = 3  -> D 串按 0x33（数字键 3）
      稿子 = g  -> D 串按 0x47（G）

【F9/F10 有时失灵、点不到「开始」怎么办（v1.7.0）】

【日语/数字/带符号的队友名字 & 取消下蹲（v1.7.2）】

    · 前提: 他的名字能在左下角队伍栏里读到(日语名现在也能了)。

  四、自己验证: 在局内跑一次

【朝队友跑动怎么跑的（v1.8.0）】
每 15 秒左右会有一段"朝队友冲刺"，持续 10~20 秒，动作是：
  1. 先按一下「镐子」键（默认 F，可在 [10] 里改）——每次都按，然后**停 0.45 秒**等镐子切出来
  2. 镐子切出来之后，才按住 W + 奔跑键不放，全程不松开（中间只动鼠标修正方向）
  3. 需要跳的时候，在 W 一直按住的前提下点一下空格 —— 不会先松开 W 再跳
  4. 看不见队友名牌时也照样往前走，只左右转视角找人
  5. 这串结束后才松开 W / 奔跑
如果想让"朝队友跑"更频繁或更少，可以用 [10] 之外的方式调（暂时没做开关，需要的话我再加）。

      在左下角按颜色把每一行名字切出来, 算白像素占比: >=75% 活着 / <=55% 死亡
    · 纯数字行(血条上的 50/100)会被过滤, 不会当成队友
    · 任何一行颜色都认不出 -> 这一轮不动, 绝不误退
  真实截图验证: 0032(3 队友全白->都不退) / 0025(第 2 行红名->不退, 其余白) /
  smooth2(第 1 行红名+灰色骷髅+9秒倒计时 -> 判死, 其余白)

  v1.9.1 队伍栏自适应 + 队友在背后会转身
    · 不再用固定的屏幕比例去找队伍栏: 进局后第一次读到队友名字时,
      程序会自己记住"这支队伍的队伍栏在屏幕的哪个位置"(相对坐标), 
      之后像素分行就只在这个区域里扫; 换分辨率/改 UI 比例都能自适应。
      (回大厅会清空, 下一局重新学)
    · 队友名牌跑到屏幕下半部分(=人在我背后/侧后) -> 直接转身 150~180°,
      不再只是小角度左右看(以前那样永远走不过去)。
    · 名牌贴在屏幕左右边缘 -> 大角度往那边转 45~85°。
    · 完全找不到人 -> 朝同一方向连续大角度扫视(能扫到背后), 不再随机抖动。

  v1.9.2 把"写死的位置"改成"看画面里的字自己找"
    以前两个地方是写死屏幕比例的, 换个分辨率/UI 比例就可能点歪:
      ① 局内 ESC 侧栏右上角的 ☰ 菜单按钮
      ② 大厅认不出「开始」时的兜底点击位置

【v1.9.3 找队友：先"瞄准居中"，再按住 W】

以前是"一边走一边大概转个头"，所以你看到它经常低着头、对着屏幕边缘发呆。
现在改成闭环瞄准：

1. 每串开始时先按稿子(镐子)键，停 0.45 秒，让镐子真的切出来
2. 然后【只转视角，不走】，直到队友名字落到屏幕正中
   · 名字在屏幕上方  -> 抬头 + 往左/右转
   · 名字在屏幕下方  -> 只往左/右转身，绝不低头（落地默认就是低头）
   · 名字贴左右边缘  -> 往那一侧大角度转过去
   · 完全看不到名字  -> 朝同一个方向扫视 70~115°，并且隔一次扫视抬一点头
3. 名字到中间之后，才按住 W（+奔跑）往前走
4. 跑的过程里每一轮都重新看一次名字位置，继续微调（上下左右都调）

参数：屏幕正中判定 = 水平 ±6% 宽、垂直 ±6% 高。

【v1.9.4 修了一个"在战斗巴士上被退对局"的 bug】

现象：满编 4 人上了战斗巴士，还没跳伞，它自己按 ESC 退对局了。

原因：战斗巴士上屏幕不显示自己的名字/血量，左下角队伍栏也读不到名字，
旧的检查把"读不到"误当成"只有我一个人" -> 开局前人数不足 -> 退局重排。

现在：
· 战斗巴士 / 跳伞阶段：完全不查队伍人数（这段看不到东西）
· 等待区：读不到任何队友名字时保守不动（可能名字还没刷出来）
· 只有"局内且自己在队伍栏里能看到"时才按队友名字颜色判断要不要退

【v1.9.5 修「找队友时头抬太高、一直看天」】

现象：转视角找队友时，有时候头越抬越高，最后在仰头看天；
这时队友名字反而被顶到屏幕下方，就越找越找不到。

原因：找人的扫视里"隔几轮抬一下头"是一直累加的，没有上限。

现在：
· 抬头有上限：累计最多抬头 28°，到 -18° 就自动往回低
· 名字出现在屏幕下方、而且当前已经抬头过多时 -> 先低头回水平，再转身（不再仰着头转）
· 正常找队友：在"稍微低头看地面"和"微微抬头"之间来回，不会偏向一头
· 名字在上方 8% 以内 -> 不额外抬头；下方 8% 以内 -> 不额外动作

【v1.9.6 / v1.9.7 修「仰头看天」「队伍栏识别错」「队友都没了也不退」】

一、仰头看天
· 原因1：每串动作开始时把"累计俯仰"清零了，于是每一串都能再往上抬，越打越仰。
· 原因2：转完视角马上截图识别，画面还在动，读到的名字位置偏了。
· 现在：俯仰偏置跨动作串保留（总上限 抬头 26°、低头 14°）；每串开始若抬头超过 14°
        先自动低头回水平；每次转完停 0.2 秒再识别。回大厅/上巴士才清零。

二、队伍栏（左下角）识别不准
· 原因：血条/护盾数字（50、95、100）被 OCR 当成"队友名字"，人数被算多，
        而且被当成"白名字 = 活着"，所以队友全倒了也不退。
· 现在：名字必须至少 2 个汉字或 3 个英文字母，纯数字/符号一律丢弃。

三、该退就退（局内，只在你自己活着时）
· 队伍栏里所有队友名字都是红/灰 -> 连续 2 轮 -> ESC→☰→返回大厅→确认
· 本局之前看到过 2 人以上、现在队伍栏只剩自己 -> 连续 2 轮 -> 回大厅
· 颜色认不出 / 一个名字都没读到 -> 这轮不动（防误退）

四、关于"屏幕最左/最下那些名字"
· 队友在近距离时会出现"名字牌"，程序会按位置转向：上方抬头、下方左右转身、
  左右边缘大角度转，直到名字落到屏幕中间
· 600~900 米那种只有"屏幕边缘的方向箭头 + 距离"，那不是名字牌，程序不会当目标去追；
  它会左右扫视找人，扫不到就继续原来的路线走

【v1.9.8 转向规则：就看名字在屏幕的哪边】

名字在屏幕左边 -> 往左转；在右边 -> 往右转；在上方 -> 顺带抬头；
在下方/左下/右下 -> 只左右转（不低头）；转到名字落在屏幕中间为止。

这版又放宽了三处：
· 名字出现在画面最上/最下边缘时也算方向（不再只认中间那块）
· 名字贴左右边缘时转得更大（约 50~57°），不是只挪一点点
· 之前的抬头/低头上限、队伍栏判定、只剩自己就退，全部保留

【v1.9.9 队伍人数：两套机制合并，认得更准】

以前只靠一套：要么只读"队伍栏名字"，要么只在读不到时用"像素分行"。
两套各有一半机会漏行（名字太小/日文/紫雾），所以人数经常少算 1~2 个。

现在 `team_info()` 把两套合起来算：
· 名字行机制：OCR 读每行名字 + 名字颜色（白=活/红灰=死）
· 像素行机制：不依赖 OCR，按行切带后判白/红
· 人数取两者最大值（封顶 4 人），死活优先信名字行、读不到用像素行兜底
· 只要综合结果里还有 1 个活着的队友 -> 绝不退对局
· 队伍栏只剩自己、或队友名字全红/灰 -> 连续 2 轮 -> 返回大厅

日志里每一轮都会写：
    队伍 4 人 (名字行 3 / 像素行 4, 活 3 倒 0 认不出 0)

【v1.10.1 启动器自查：修掉 10 条】

这次专门查的是"启动器"（那个命令行界面），不是挂机脚本本身。高危 4 条：

1) 在提示符按 Ctrl+C 会被当成"输入结束"，直接退出但不停止挂机
   → 机器人留在后台继续跑；现在 Ctrl+C 会先停挂机再退出。
2) 关掉启动器窗口再打开，会显示"未运行"，按 2 也说"无需停止"
   → 其实机器人还在后台跑，停不掉。现在会读 bot.pid，能认出并在 [2]/[3] 停掉。
3) 按 2 停止时只等 0.8 秒就强杀，残留的 控制.txt=stop 会让下次按 1 起的新进程
   一启动就自我取消（界面显示"已开始挂机"，实际在待命）
   → 现在启动前先写 控制.txt=start，且停止时最多等 5 秒让它自己收尾。
4) bot.pid 不校验也不删除：重启后 PID 被别的程序复用，会误判"已在运行"，
   甚至 taskkill 误杀无关进程
   → 现在 pid 文件带"进程创建时间"，对不上就丢弃；停止后自动删除。

中危 6 条（都已修）：
5) 改游戏ID 失败也报"已改好" → 现在按返回值提示。
6) 切宽松/严格模式失败也报成功 → 现在会回读校验，失败提示"没生效"。
7) 改设置时如果 设置.txt 正被机器人写，可能整份被清空（校准/键位全丢）
   → 现在改成"先写临时文件再原子替换"，且读失败时拒绝写入。
8) 菜单 12（退出策略）里直接 input()，遇到输入结束会崩 → 改用统一输入。
9) OCR 检测失败一次后会被缓存整个会话，一直显示"中文OCR缺失"，按 6 还会弹 UAC
   → 现在只有检测成功才缓存，按 6 每次重新检测。
10) 连点两次「启动.bat」可能起两个机器人抢键鼠 → 现在启动后立刻写 pid 占坑。

还有 5 条低危（菜单超宽折行、日志句柄未关等）只影响观感，没动。

  8. 有「开始」或大厅词(商城/仓库/通行证/零建造/装备一个精灵...) -> 大厅(点开始)
  9. 局内 HUD + 没有局外词 + 自己名字/方位条 -> 局内
 10. 其它 -> UNKNOWN(不动)

反挂机(走/转视角/跳跃/表情/朝队友跑)只在"局内 + 活着"才执行:
  · 画面里出现「开始」「商城」「装备一个精灵」等大厅字样 -> 一律不做
  · 出现观战字样 -> 不做
  · 出现结算页字样 -> 不做

【v1.11.1 修掉「不往队友走 / 有时完全不动」的两个真 bug】

现象：能看到队友、也能点开始，但局内就是不走、也不往队友方向跑。

原因 1（画面判定）：
  有些帧（人在水里、画面被树叶/烟雾挡住、UI 缩放偏大）时，
  Windows OCR 会同时读不到左上角任务栏「收集地图碎片 / 打开宝箱」，
  也读不到左下角自己的名字 —— 这时程序会以为「我不在局内」，
  于是整个反挂机（走路/转视角/朝队友跑）全部暂停。
  修法：把屏幕最上面的「方位条」（东/南/西/北 + 刻度数字）也算作「在局内」的铁证，
  大厅/加载/结算页都没有这排字，所以不会误判。

原因 2（朝队友跑时报错）：
  找到屏幕中间的队友名牌后，程序会算「该往哪转」。
  这段代码里用了一个不存在的变量名，一进这个分支就报错，
  报错又被上层吞掉 —— 于是「找到队友」= 什么都不做。
  修法：删掉这段遗留代码（转向已经由前面「闭环瞄准」负责，本来就不用再算一遍）。

附带修复：
  · 连续 5 轮都读不到自己名字时，不再死等，直接按「已确认在局内」继续反挂机（日志会打 WARN）。
  · 反挂机动作串里的任何异常，现在都会写进 bot_log.txt（WARN 反挂机动作出错），不再静默失败。

怎么验证：看 bot_log.txt 里有没有
  「反挂机跳过: 不在局内(UNKNOWN)」  ← 修复后应该很少见
  「WARN 反挂机动作出错」            ← 修复后应该没有

【v1.11.2 修复：画面偏色导致"我不动了"】
问题：沙漠橙、风暴紫、冰面蓝这类环境光会把左下角 HUD 一起染色。
旧逻辑按"绝对 RGB 判白/红"，橙色背景下整块区域都是"红"，于是把自己判成"已死亡"，
反挂机（走位/朝队友跑/跳跃…）就全停了 —— 表现就是"站着不动"。

现在改成只认铁证：
 · 只有整块区域"非常红"（红像素 > 45%）并且几乎看不到亮色文字，才判"我死了"；
 · 只要能读到自己的名字（亮色文字），就判"我活着"；
 · 灰色不再判死（半透明底板本来就是灰的），认不准就不表态，交给"观战字样/死亡横幅"去判。

另外：只要读到自己的名字，就会记住它在左下角的相对位置；下次名字看不清时，
按记住的位置直接看颜色，不再依赖 OCR。

【v1.11.3 修复：明明在观战，命令框却显示「结算页」】
原因有两个：
1) 死亡/被淘汰的面板上也有「返回大厅」按钮（小队模式还带「观战」），
   旧逻辑看到「返回大厅」就先按结算页处理 —— 于是命令框显示"结算页面"，
   而且队友还活着时可能被它点掉「返回大厅」提前退局。
2) 命令框读日志的正则写的是 state=(\w+)，而状态名是 RESULTS?，
   '?' 被截掉后只剩 RESULTS，查表就成了「结算页」。

现在：
 · 只要出现「被淘汰 / 阵亡 / 被风暴吞噬 / 正在旁观 / 上一个队友 / 下一个队友 / 等待重启」，
   一律先判「已阵亡·观战队友」，绝不点任何按钮；
 · 只有真正出现结算页标记（比赛回顾 / 你的排名 / 经验值 / 继续和此小队 / 胜利王冠 /
   再来一局）才算这一局结束；
 · 只有「返回大厅」但没有结算标记时，显示「疑似结算页 · 只有返回大厅, 观察中」，
   如果程序知道自己在观战，就完全不点，等小队全部结束。

【v1.11.5】输入 3 退出时，会把**所有**跟本程序有关的进程一起结束掉：
